AI UX QA Agent

What is this?

AI UX QA Agent is a local dashboard that queues browser QA runs and helps product teams review evidence and findings.

It does two jobs:

  • Collect evidence. Screenshots, network, console and accessibility checks.
  • Review findings. Inspect AI suggestions and guideline checks before deciding what to fix.

Who is it for?

Product engineers and reviewers use the dashboard at localhost:3000; the API runs at localhost:8000, with local browser and AI worker processes.

It makes repeatable browser checks and human review available in one place. Tools used: Next.js. New words or tool names? See the first two rows.

Run and test

1

Local development

From the repository root, start Docker services, install dependencies with pnpm install, then pnpm dev. pnpm dev:web starts only the web; API uses uvicorn app.main:app --reload --port 8000 from apps/api. NEXT_PUBLIC_API_BASE_URL must reach the API. See .env.example for configuration.

Uses: Docker Compose + pnpm + uvicorn

→
2

JavaScript verification

From the repository root, run pnpm validate, pnpm test, pnpm e2e and pnpm build. Vitest covers UI, API, theme contrast, polling and stale responses; Playwright mocks localhost:8000 and covers review, queue, clear, focus, tab order and reduced motion. Install Chromium before E2E. CI also runs actionlint for workflows and Gitleaks for secrets.

Uses: ESLint + Prettier + TypeScript + Vitest + Playwright

→
3

Python verification

Keep the existing commands: ruff check apps workers; ruff format --check apps workers; python -m pytest -v inside apps/api and workers/ai. Python files and dev.sh are outside this tooling migration.

Uses: Ruff + pytest
